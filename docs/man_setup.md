# setup

## Nombre

setup — prepara el entorno local

## Sinopsis

```
just setup
make man TARGET=setup
```

## Descripción

Instala los git hooks (`core.hooksPath = .githooks`) y descarga los módulos Go.

## Ejemplos

```bash
just setup
```
